# 📊 Power BI Interactive Business Dashboard

## 🎯 Hadafka Mashruuca (Project Objective)
Mashruucan waxaan ku dhisay Dashboard casri ah oo isbedbeddela (Interactive Dashboard) si loo falanqeeyo waxqabadka ganacsiga, dakhliga, iyo macaashka shirkadda.

## 🛠️ Xirfadaha Power BI ee la adeegsaday (Power BI Skills Used)
* **Data Modeling:** Isku xidhka jadwalka xogta (Star Schema).
* **DAX Formulas:** Qorista koodhka DAX si loo xisaabiyo isbeddelka iibka (YoY Growth, Profit Margin).
* **Advanced Visuals:** Isticmaalka Slicers, Bar Charts, iyo Key Performance Indicators (KPIs).
